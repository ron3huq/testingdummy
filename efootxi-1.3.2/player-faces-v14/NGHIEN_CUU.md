# V14: move beyond static pointer confirmation

Phone v13 log is current and matches published runtime/native hashes: mesh_texture_confirmed3, head_material_confirmed6648, rebinds0, failures0, component_mismatch0. The reported head is still black. Therefore v12/v13 static-binding success does NOT establish shader correctness; do not claim another pointer-binding-only fix. head_binding_state_bits93 indicates the alternate component holds the private mesh; special selector is set but special actor MID cache is missing, while regular cache exists. This is evidence of different material/bake routing, not proof of a final cause.

Static Face MICs normalized across good/bad heads are identical; normalized Texture2D property/platform prefixes are also identical by channel. Vertex color is white for both groups; normals/UV ranges and handedness have no pattern unique to the four failures (working Dinh Bac also uses derived handedness). No head asset changes are justified by those comparisons. Skin normal/SRO payload differences remain, but flattening them in earlier versions did not fix the device issue.

Native inspection: 0x39c6618 creates the special actor MID only on certain bake transitions; 0x39cb75c calls it after a bake-cache readiness condition. Setter0x39c728c selects actor1ab8 if1a5d is set; absent special cache explains old guard skips but is insufficient to explain why a valid static MIC is black. Avoid setting actor flags/IDs/global Face recognition and avoid another speculative normal/texture rewrite.

V14 uses native UMaterialInstanceDynamic::Create at0x59b817c(parent,outer). The actual body creates a MID through native StaticConstructObject and initializes parent via0x59af810. Explicit texture overrides through0x59b8644 cause the normal material resource/uniform update path; getters0x59b8a2c/0x59ab210 verify CPU-side identity. BaseColorMap/NormalMap/SROMap must all match the same private profile+suffix. Parent MIC remains immutable. Bind through GetMaterial0x588/SetMaterial0x590 only when component+0x468 equals the verified private mesh. Cache only component-referenced MIDs; never dereference a previously unbound cached UObject. Cache hits additionally require the live component material's Outer==actor and Parent==source. Two possible component references are accommodated.

502 Unicorn tests execute the hook/factory/getter bodies, while object construction, parent resource initialization, material updates and GPU are modeled. This cannot prove actual rendering or fully validate Android GC; document that limit. Device confirmation remains required. New MID counters distinguish this experiment from v13's already-working static assignment.

Cards: pc1000 has older IDs, pc1001 in resources-02 has five newer requested IDs. Both original containers were inspected/extracted locally before asking for phone files. Reuse exact native package IDs, header/mip/dimensions/imports; change only ETC2RGBA pixel bytes. Nineteen UI textures verified through independent UEViewer exports. Xuan Son large portrait and all277head chunks stay byte-identical to v13.
