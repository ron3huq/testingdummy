# V23 build and boundaries

Incremental baseline: v22 main ZIP, SHA256 `6d1813d0bea06474481d69d55e4250b1d2ab73ff3ca0cb89865ab9070febb843`. Restore its three livedata files into `../player-faces-v22/container/`. Build environment: Python 3.12, numpy/scipy/Pillow, cityhash, etcpak, texture2ddecoder, libarchive-c, pyelftools, unicorn, ziglang 0.13.0. `/workspace/ronaldo-work` holds the audited PES FMDL reader, native UE4 libraries, independent UEViewer and previously recovered user models; those large engine dependencies are not embedded in this source archive.

`build_heads.py` rebuilds 11 variants from actual FMDL skin/scalp and hair, not the previous donor UV correspondence. Working ND06 supplies skeleton/LOD metadata, native eyes/oral and skin/hair material templates. FOX shell/eyeline/collar AO passes are excluded from the opaque skin. Source positions/triangle winding are retained through coordinate conversion; skin UVs occupy half-atlas tiles. Özil V2 uses the actual `face_bsm` and a separate scalp tile from `hair_bsm_alp`. Named bone aliases map to native controls; extra ear/collar helpers map to head/neck, with nearest native neck influences on the lower seam. Source expressions are reduced to native eye/jaw/lid controls, not a promise of full PC facial rig support.

Inputs: supplied latest 2017/2027 recoveries under `v20-input/{2017,2027}`, original Jr/HD under `input-junior`, `input-hoang-duc`, and new Özil under `v23-input/ozil`. Archive `original-inputs/Mesut_OZIL_V2.rar` is included; safe extraction and DDS-to-PNG recovery precede build. Native ND06 mesh logs/FMDL are in prior v20 references. The input 2006 FMDLs are used by `source-comparison.json`, not to replace the new supplied head shapes.

`pack_minis.py` is executed by the head builder before one Bundle write. Photographic editing uses image_gen; packing uses measured per-cell head bounds and uniform scaling. Four heads are centered on x=64, top=8 and height=85 in 128-square textures. All old large-card art remains byte exact. `Mini-preview.png` shows the independent mini layout, not an Android UI screenshot.

`sh source/build_native.sh` compiles v21 native C plus only a pure `noodle_stat_word` function for diagnostic uint64 reconstruction. No draw-probe code or exports are retained. Test card maps back to NW01, no NT01 texture redirect. Runtime version is `player-faces-v23-source-rebuild-stability`; manifest increment is 41.

Validate: `verify_assets.py` requires a native-resource reader at `/workspace/ronaldo-work/v23-reader` with this completed container, and writes independent reader logs. UEViewer's known message that animation export requires the mesh viewer is ignored; mesh/texture exports and all other errors are checked. `validate_stability.py` runs 578 baseline native checks then verifies exact v21 C equality except the pure reporting function, absent probe exports and full IDs. `validate_install.py`, `validate_squad_abi.py`, `validate_trampoline_hints.py` cover installation and the prior builder ABI crash. Engine bodies at native boundaries are modeled; no host check is an Android renderer test.

Stage eight work files from pinned v21 main ZIP SHA256 `5b8065ff4f2d2cb32deaa77f669a839c7469cfce84134ee8e8790b4e216fed4f`; replace noodle Python/SO/bundle metadata and three container files. Do not include user save/config data. `validate_runtime.py` verifies the staged tree, then `package_release.py` creates one install archive and a source archive. Read package/asset/stability reports for exact scope and phone-verification limits. V22 reported a crash, but no fatal stacktrace was provided; v23 deliberately withdraws its probe/control/new Ex assets rather than claiming a proven crash site.
